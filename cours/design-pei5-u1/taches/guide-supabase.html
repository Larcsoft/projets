Mise en route · une seule fois · environ 20 minutes

Relier les pages à Supabase

Un seul compte gratuit pour tous vos cours. Les élèves entrent un code anonyme et retrouvent leur travail sur n’importe quel ordinateur ; vous suivez tout depuis le tableau de bord.

Ce que vous obtenez

  • Chaque élève tape un code anonyme (ex. E-K7MQ3X) en haut de la page.
  • Son travail s’enregistre tout seul : champs, tri, QCM, brouillon et version finale.
  • Sans Internet, la page fonctionne quand même et envoie le travail quand la connexion revient.
  • Dans le tableau de bord, vous voyez ✎ (brouillon) ou ✓ (version finale), les scores et le détail, et vous pouvez tout exporter en CSV.

L’enregistrement est discret : aucun voyant ni aucun message dans les pages des élèves. Les pages ne disent rien de faux pour autant : la phrase « tes réponses restent sur cet ordinateur » disparaît quand elles sont reliées. Une phrase pour la charte de rentrée vous est proposée à l’étape 9.

1. Créer le projet

  1. Allez sur supabase.com, cliquez sur Start your project et créez un compte, avec GitHub ou une adresse courriel.
  2. Cliquez sur New project et remplissez :
    • Name : pages-activites ;
    • Database Password : un mot de passe long, à garder (les pages n’en ont pas besoin) ;
    • Region : une région d’Europe (Paris ou Francfort) ;
    • Plan : Free.
  3. Attendez environ 2 minutes que le projet soit prêt.

2. Installer les tables et la sécurité

  1. Dans le menu de gauche, ouvrez SQL Editor, puis cliquez sur New query.
  2. Cliquez ci-dessous sur Copier le script, puis collez-le dans l’éditeur (Ctrl+V).
  3. Cliquez sur Run. Vous devez lire Success. No rows returned.

Voir le script (environ 280 lignes)
-- =====================================================================
-- Pages d'activités · Installation Supabase (un seul projet pour TOUS les cours)
-- À coller en une fois dans Supabase > SQL Editor > New query > Run.
-- Le script peut être relancé sans perte de données.
--
-- Principe de sécurité (élèves mineurs) :
--   * aucune donnée personnelle : ni nom, ni courriel. Un code élève
--     (stocké sous forme d'empreinte), une classe, des inscriptions à des cours ;
--   * les élèves n'ont AUCUN accès direct aux tables (RLS sans règle pour
--     « anon ») : les pages passent par 3 fonctions qui vérifient le code
--     et l'inscription au cours ;
--   * seul un compte enseignant (Supabase Auth) lit les travaux, crée les
--     cours et les codes.
-- =====================================================================

create extension if not exists pgcrypto with schema extensions;

-- ---------- Tables ----------

create table if not exists public.cours (
  id        text primary key check (id ~ '^[a-z0-9-]{2,40}$'),   -- ex. design-pei5-u1
  titre     text not null,
  cree_le   timestamptz not null default now()
);

create table if not exists public.eleves (
  id         uuid primary key default gen_random_uuid(),
  code_hash  text not null unique,     -- empreinte SHA-256 du code, jamais le code lui-même
  code_fin   text not null,            -- 2 derniers caractères, pour s'y retrouver
  classe     text not null,
  cree_le    timestamptz not null default now(),
  vu_le      timestamptz
);

create table if not exists public.inscriptions (
  eleve_id  uuid not null references public.eleves(id) on delete cascade,
  cours_id  text not null references public.cours(id) on delete cascade,
  choix     text,                       -- choix propre au cours (ex. le projet : lampe, jeu…)
  primary key (eleve_id, cours_id)
);

create table if not exists public.reponses (
  eleve_id   uuid not null,
  cours_id   text not null,
  activite   text not null check (activite ~ '^[A-Za-z0-9_-]{1,40}$'),   -- ex. A1, fiche-3
  donnees    jsonb not null default '{}'::jsonb,   -- brouillon : tous les champs de la page
  finale     text not null default '',             -- version finale reformulée
  maj        timestamptz not null default now(),
  primary key (eleve_id, cours_id, activite),
  foreign key (eleve_id, cours_id) references public.inscriptions(eleve_id, cours_id) on delete cascade
);

create table if not exists public.enseignants (
  user_id uuid primary key references auth.users(id) on delete cascade
);

-- ---------- Sécurité au niveau des lignes ----------

alter table public.cours        enable row level security;
alter table public.eleves       enable row level security;
alter table public.inscriptions enable row level security;
alter table public.reponses     enable row level security;
alter table public.enseignants  enable row level security;

revoke all on public.cours, public.eleves, public.inscriptions, public.reponses, public.enseignants from anon;

create or replace function public.est_enseignant()
returns boolean
language sql stable security definer set search_path = public
as $$
  select exists (select 1 from public.enseignants where user_id = auth.uid());
$$;

do $$
declare
  t text;
begin
  foreach t in array array['cours', 'eleves', 'inscriptions', 'reponses'] loop
    execute format('drop policy if exists "enseignant" on public.%I', t);
    execute format('create policy "enseignant" on public.%I for all to authenticated
                    using (public.est_enseignant()) with check (public.est_enseignant())', t);
  end loop;
end;
$$;

drop policy if exists "enseignant se voit" on public.enseignants;
create policy "enseignant se voit" on public.enseignants
  for select to authenticated using (user_id = auth.uid());

-- ---------- Fonctions utilitaires ----------

create or replace function public.empreinte(p_code text)
returns text
language sql immutable
set search_path = public, extensions
as $$
  select encode(extensions.digest(upper(trim(p_code)), 'sha256'), 'hex');
$$;

-- ---------- Fonctions appelées par les pages élèves ----------

-- Connexion : vérifie le code et l'inscription au cours ; renvoie la classe et le choix
create or replace function public.eleve_connexion(p_code text, p_cours text)
returns json
language plpgsql security definer
set search_path = public, extensions
as $$
declare
  v_id uuid;
  v_classe text;
  v_choix text;
begin
  select e.id, e.classe, i.choix into v_id, v_classe, v_choix
  from public.eleves e
  join public.inscriptions i on i.eleve_id = e.id and i.cours_id = p_cours
  where e.code_hash = public.empreinte(p_code);
  if v_id is null then
    return null;
  end if;
  update public.eleves set vu_le = now() where id = v_id;
  return json_build_object('classe', v_classe, 'choix', v_choix);
end;
$$;

-- Enregistre le brouillon et la version finale d'une activité
create or replace function public.eleve_enregistrer(p_code text, p_cours text, p_activite text,
                                                    p_donnees jsonb, p_finale text, p_choix text)
returns timestamptz
language plpgsql security definer
set search_path = public, extensions
as $$
declare
  v_id uuid;
  v_maj timestamptz := now();
begin
  select e.id into v_id
  from public.eleves e
  join public.inscriptions i on i.eleve_id = e.id and i.cours_id = p_cours
  where e.code_hash = public.empreinte(p_code);
  if v_id is null then
    raise exception 'code inconnu ou élève non inscrit à ce cours';
  end if;
  if length(coalesce(p_donnees, '{}'::jsonb)::text) > 200000 or length(coalesce(p_finale, '')) > 50000 then
    raise exception 'texte trop long';
  end if;
  insert into public.reponses (eleve_id, cours_id, activite, donnees, finale, maj)
  values (v_id, p_cours, p_activite, coalesce(p_donnees, '{}'::jsonb), coalesce(p_finale, ''), v_maj)
  on conflict (eleve_id, cours_id, activite) do update
    set donnees = excluded.donnees, finale = excluded.finale, maj = excluded.maj;
  if p_choix is not null and length(p_choix) <= 40 then
    update public.inscriptions set choix = p_choix where eleve_id = v_id and cours_id = p_cours;
  end if;
  return v_maj;
end;
$$;

-- Relit ce que l'élève a déjà écrit pour une activité
create or replace function public.eleve_lire(p_code text, p_cours text, p_activite text)
returns json
language plpgsql security definer
set search_path = public, extensions
as $$
declare
  v_donnees jsonb;
  v_finale text;
  v_maj timestamptz;
begin
  select r.donnees, r.finale, r.maj into v_donnees, v_finale, v_maj
  from public.reponses r
  join public.eleves e on e.id = r.eleve_id
  where e.code_hash = public.empreinte(p_code) and r.cours_id = p_cours and r.activite = p_activite;
  if v_maj is null then
    return null;
  end if;
  return json_build_object('donnees', v_donnees, 'finale', v_finale, 'maj', v_maj);
end;
$$;

-- ---------- Fonctions réservées à l'enseignant(e) ----------

drop function if exists public.creer_codes(text, text, int);

-- Crée des codes pour une classe et les inscrit à un cours.
-- Renvoie les codes en clair UNE SEULE FOIS : imprimez-les ou notez-les.
create or replace function public.creer_codes(p_classe text, p_cours text, p_nombre int)
returns table (code text, eleve_id uuid)
language plpgsql security definer
set search_path = public, extensions
as $$
declare
  lettres text := 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';   -- sans I, O, 0, 1 (confusions)
  c text;
  i int := 0;
  k int;
  v_id uuid;
begin
  if not public.est_enseignant() then
    raise exception 'réservé à l''enseignant(e)';
  end if;
  if p_nombre < 1 or p_nombre > 60 then
    raise exception 'entre 1 et 60 codes à la fois';
  end if;
  if not exists (select 1 from public.cours where id = p_cours) then
    raise exception 'cours inconnu : %', p_cours;
  end if;
  while i < p_nombre loop
    c := 'E-';
    k := 0;
    while k < 6 loop
      c := c || substr(lettres, 1 + (get_byte(extensions.gen_random_bytes(1), 0) % 32), 1);
      k := k + 1;
    end loop;
    begin
      insert into public.eleves (code_hash, code_fin, classe)
      values (public.empreinte(c), right(c, 2), p_classe)
      returning id into v_id;
      insert into public.inscriptions as ins (eleve_id, cours_id) values (v_id, p_cours);
      code := c;
      eleve_id := v_id;
      return next;
      i := i + 1;
    exception when unique_violation then
      -- code déjà pris (très rare) : on en tire un autre
    end;
  end loop;
end;
$$;

-- Inscrit tous les élèves d'une classe à un autre cours (ils gardent leur code)
create or replace function public.inscrire_classe(p_classe text, p_cours text)
returns int
language plpgsql security definer
set search_path = public
as $$
declare
  n int;
begin
  if not public.est_enseignant() then
    raise exception 'réservé à l''enseignant(e)';
  end if;
  insert into public.inscriptions (eleve_id, cours_id)
  select id, p_cours from public.eleves where classe = p_classe
  on conflict do nothing;
  get diagnostics n = row_count;
  return n;
end;
$$;

-- ---------- Droits ----------

revoke all on function public.eleve_connexion(text, text),
  public.eleve_enregistrer(text, text, text, jsonb, text, text),
  public.eleve_lire(text, text, text), public.creer_codes(text, text, int),
  public.inscrire_classe(text, text), public.est_enseignant(), public.empreinte(text) from public;
grant execute on function public.eleve_connexion(text, text) to anon, authenticated;
grant execute on function public.eleve_enregistrer(text, text, text, jsonb, text, text) to anon, authenticated;
grant execute on function public.eleve_lire(text, text, text) to anon, authenticated;
revoke execute on function public.creer_codes(text, text, int), public.inscrire_classe(text, text) from anon;
grant execute on function public.creer_codes(text, text, int) to authenticated;
grant execute on function public.inscrire_classe(text, text) to authenticated;
grant execute on function public.est_enseignant() to authenticated;
grant select, insert, update, delete on public.cours, public.eleves, public.inscriptions to authenticated;
grant select, delete on public.reponses to authenticated;
grant select on public.enseignants to authenticated;

Le script peut être relancé sans perte de données, par exemple après une mise à jour. Il est aussi fourni à part, dans le fichier supabase_installation.sql.

3. Créer votre compte enseignant(e)

  1. Ouvrez Authentication, puis Users, puis Add user et Create new user.
  2. Saisissez votre adresse et un mot de passe, puis cochez Auto Confirm User.
  3. Dans Authentication, ouvrez Sign In / Providers et désactivez Allow new users to sign up. Un inscrit ne verrait rien de toute façon, mais c’est plus propre.

4. Vous déclarer enseignant(e)

Tapez votre adresse (celle de l’étape 3) : la ligne se met à jour toute seule.

insert into public.enseignants (user_id) select id from auth.users where email = 'votre.adresse@exemple.org';

Dans SQL Editor, ouvrez une nouvelle requête (New query), collez la ligne, puis cliquez sur Run. Vous devez lire 1 row. Si vous lisez 0 rows, l’adresse ne correspond pas exactement à celle de l’étape 3.

5. Récupérer l’adresse et la clé publique

  1. En haut de la page du projet, cliquez sur Connect. Vous pouvez aussi passer par Settings, puis API Keys.
  2. Notez :
    • l’URL du projet, du type https://abcdefgh.supabase.co ;
    • la Publishable key, qui commence par sb_publishable_. L’ancienne clé anon public, qui commence par eyJ, fonctionne aussi.

Ces deux valeurs sont faites pour être publiques : la sécurité repose sur les règles installées à l’étape 2.

Ne copiez jamais la clé secret ni la clé service_role : elles ouvrent tout.

6. Relier les pages

Le plus simple : envoyez l’URL et la clé publishable dans le fil du projet. Les pages sont alors régénérées pour vous.

Vous-même (avec Python et python-docx installés) :

  1. Dans le dossier sources/, créez le fichier config_supabase.json : 
    { "url": "https://abcdefgh.supabase.co", "cle": "sb_publishable_xxxxxxxx", "cours": "design-pei5-u1" }
  2. Depuis sources/, lancez python3 build.py ..

Ne modifiez pas les pages à la main : la régénération met aussi à jour les textes qui parlent de l’enregistrement.

7. Essayer avant la classe

  1. Ouvrez le tableau de bord et connectez-vous.
  2. Dans 2. Codes des élèves, créez 2 codes pour une classe ESSAI.
  3. Ouvrez A1, entrez un des codes, écrivez quelques mots et faites le tri.
  4. Rouvrez A1 sur un autre ordinateur, ou dans une fenêtre de navigation privée, avec le même code : le travail réapparaît.
  5. Dans le tableau de bord, cliquez sur Actualiser : la case A1 de l’élève affiche ✎ ou ✓, avec le score du tri.

Pour effacer la classe d’essai, exécutez cette ligne dans SQL Editor :

delete from public.eleves where classe = 'ESSAI';

8. En classe et dans vos autres cours

  • Codes. Ils ne s’affichent qu’une fois, au moment où vous les créez. Tapez le nom de chaque élève à côté, puis imprimez la liste et découpez-la. Les noms restent sur votre ordinateur : pensez à Exporter les noms de temps en temps.
  • Code perdu. Il est impossible de le retrouver, car Supabase n’en garde qu’une empreinte. Créez un nouveau code : l’ancien travail reste visible sous l’ancien code.
  • Poste partagé. L’élève retape son code à chaque ouverture du navigateur. Changer de code efface le travail du poste, mais il reste en ligne.
  • Autres cours. Créez le cours dans le tableau de bord, puis inscrivez-y une classe existante : les élèves gardent leur code. Dans les pages de ce cours, ajoutez commun/socle.js. La page exemple-qcm.html montre comment faire, et le fichier GUIDE_SUPABASE.md donne le détail.
  • Pause du plan gratuit. Le projet se met en pause après 7 jours sans aucune visite, pendant les vacances par exemple. Les données sont conservées : dans Supabase, cliquez sur Restore project avant la reprise des cours.
  • Fin d’année. Exportez les CSV, puis exécutez delete from public.eleves where classe = 'PEI5-A'; pour chaque classe. Les réponses de ces élèves sont effacées avec eux.

9. Phrase pour la charte ou l’information de rentrée

Certaines activités du cours se font sur des pages web. Le travail de l’élève (réponses, brouillons, versions finales, résultats aux exercices) y est enregistré automatiquement sous un code anonyme. L’élève le retrouve ainsi d’un ordinateur à l’autre, et l’enseignant(e) peut suivre les progrès et adapter son aide. Aucun nom ni aucune adresse n’est enregistré en ligne : seul(e) l’enseignant(e) sait à quel élève correspond chaque code. Les données sont hébergées en Europe (Supabase) et effacées à la fin de l’année scolaire.

Les élèves étant mineurs, cette information va aussi aux familles, par exemple avec la charte informatique signée en début d’année. Elle reste générale et ne précise pas quand vous consultez les réponses : vous pouvez toujours observer l’implication réelle des élèves, sans rien leur cacher sur le principe.
