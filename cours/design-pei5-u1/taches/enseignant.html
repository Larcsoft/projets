Connexion

1. Cours

Créer un nouveau cours

L’identifiant est court, en minuscules, sans espace ni accent (ex. design-pei4-u3). C’est lui qu’on écrit dans la configuration des pages de ce cours.

2. Codes des élèves

Chaque élève reçoit un code, valable pour tous vos cours. Le code n’est montré qu’une seule fois : notez le nom de l’élève à côté, puis imprimez la liste.

Inscrire une classe déjà créée à ce cours
