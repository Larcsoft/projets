Les trois projets témoins portent sur le même thème, l’arrosage du jardin, pour que tu puisses comparer la façon dont chaque tâche se fait selon l’outil.

  • Électronique · Arduino ou ESP32Arrosage automatique du jardinUn capteur d’humidité du sol commande, par un relais, une mini-pompe 5 V.
  • Jeu · PyGameGoutte à goutteArroser les six planches du jardin scolaire sans gaspiller l’eau du puits.
  • Application · ThunkableMon sac compteCompter les réutilisations d’un sac en coton pour savoir quand il devient plus écologique qu’un sac plastique.

Un exemple, pas un modèle à copier. Ce projet témoin a été rédigé pour montrer une trace de niveau 7-8. Il porte sur un autre sujet que le tien. Les personnes, les enquêtes et les tests avec des utilisateurs sont inventés pour l’exemple ; c’est signalé dans le document.
