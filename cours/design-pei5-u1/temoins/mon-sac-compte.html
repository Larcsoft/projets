1Le projet en bref

Un sac en coton n’est plus écologique qu’un sac plastique qu’après un grand nombre d’utilisations : environ 131 selon l’Agence de l’environnement du Royaume-Uni (2011). L’application Mon sac compte, faite dans Thunkable, enregistre chaque réutilisation d’un objet durable et montre où l’on en est par rapport à ce seuil.

Comme ton projet Répar’Lomé, ce témoin a trois niveaux : une liste dans l’application, puis une base Supabase lue par une requête d’API, puis l’écriture dans la base depuis l’application, avec un code QR.

Un exemple, pas un modèle à copier. Ce projet témoin a été rédigé par l’enseignant(e) pour montrer une trace de niveau 7-8. Il porte sur un autre sujet que le tien. Les personnes, les enquêtes et les tests avec des utilisateurs sont inventés pour l’exemple ; c’est signalé dans le document.

Lire la trace complète en ligne, de A1 à D4. C’est la même trace que le document Word, présentée comme un article.
