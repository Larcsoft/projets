# Site des cours

Site statique publié avec GitHub Pages. Aucune installation : ce ne sont que des pages HTML.

- `index.html` : la page d'accueil, avec la liste des cours.
- `cours/design-pei5-u1/` : Design PEI 5, unités 1 et 2.
  - `taches/` : les 16 pages d'activités A1 à D4.
  - `temoins/` : les trois projets témoins (arrosage, Goutte à goutte, Carnet d'arrosage) et leurs fichiers.
  - `trace/` : le modèle Word de la trace élève.
  - `qcm/` : les QCM de compréhension.
  - `telechargements/` : les fichiers à télécharger.
- `commun/` : le style commun à tout le site.

Pour ajouter un cours, créer un dossier `cours/<identifiant-du-cours>/` et ajouter un lien dans `index.html`.
